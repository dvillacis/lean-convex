## [Unreleased]

### Added

- `Extended/SubgradientCalculus`: the sandwich theorem for a convex and a concave function, and
  the sum, chain, constraint and finite-sum rules for subgradients on Hilbert spaces
  (`_of_continuous`, `_of_continuousAt`), with the finite-dimensional statements as corollaries.
  For extended-real functions, the sum and chain rules under an interior point of the domain and,
  in finite dimension, under the relative-interior qualification (Rockafellar, Thm 23.8 and 23.9).
- `Extended/FenchelYoung`: reciprocity `s ∈ ∂f(x) ↔ x ∈ ∂f*(s)` (Rockafellar, Thm 23.5) under
  `f** x = f x`, under `(cl f) x = f x`, and for lower semicontinuous convex functions on a
  Hilbert space.
- `Extended/AffineMinorantHilbert`: a lower semicontinuous convex function on a Hilbert space is
  the supremum of its continuous affine minorants.
- `Algorithm/ChambollePock`: boundedness of the iterates, the ergodic `O(1/N)` rate for the
  partial primal–dual gap and, in finite dimension, convergence to a saddle point
  (Chambolle–Pock, Thm 1).

### Changed

- `bi_convex_conjugate_eq_self`, `convex_conjugate_congr_iff` and
  `ccp_convex_conjugate_bijective` hold on Hilbert spaces (`[CompleteSpace E]`) instead of
  finite dimension.

## [0.1.2] - 2026-11-25

### Added

- Continuous integration on every pull request: build with no warnings, `lake exe mk_all --check`,
  the tests and the axiom audit.
- `ConvexAnalysisTest`, a test library run by `lake test`: it restates the main results with
  their hypotheses written out, so that a change to one of these statements is noticed, and it
  compiles the example of the README.
- API documentation at <https://david.villacis.net/lean-convex/docs/>, rebuilt on every push to
  `main`.
- Compiled release archives for macOS arm64, next to Linux x86_64.
- Package metadata in `lakefile.toml` (description, keywords, license).
- `CHANGELOG.md`, `CITATION.cff` and `CONTRIBUTING.md`.

- A docstring for every definition, structure and structure field (217 were missing), and a
  module docstring for every file.

### Changed

- Mathlib's standard set of style linters is enabled (except `linter.flexible` and
  `linter.style.multiGoal`), and the library complies with it: spacing, line lengths, `show` to
  `change`, focusing dots, file headers. No declaration was renamed, and no statement or
  definition changed (checked by comparing all 1,914 declarations before and after).
- File headers: `Author:` is now `Authors:`; `Extended/EReal` and `Extended/IntrinsicInterior`
  get an `Authors:` line with the names of their copyright line; `Extended/ConvexConjugate`,
  `Extended/ConvexIndicator` and `Extended/ConvexSupport`, which have no header upstream, get
  one naming "The Reaslib authors".
- `scripts/AuditAxioms.lean` fails when a declaration depends on a non-standard axiom.
- The root file `ConvexAnalysis.lean` is generated by `lake exe mk_all`.

## [0.1.1] - 2026-11-24

### Changed

- The library builds with no warnings against Mathlib `v4.33.1`. Only proofs changed; no
  declaration was renamed and no statement changed.

## [0.1.0] - 2026-11-21

First tagged release: the port of the 36 OptLib files (theory and algorithms) and of 9 Reaslib
files to Mathlib `v4.33.1`, with the six upstream `sorry`s proved, and 6 added files. See
`PORTING.md`.
